VYNT Analytics

Overview

VYNT Analytics provides creators with structured information about content performance.

Tracked Metrics

Where authorized data is available, VYNT can work with metrics including:

* Views
* Likes
* Comments
* Shares
* Saves
* Watch time
* Completion rate
* Profile visits
* Engagement rate

Performance Analysis

VYNT can analyze performance across:

* Individual content
* Creators
* Games
* Topics
* Keywords
* Time periods
* Content types

Engagement Rate

VYNT can calculate an internal engagement rate:

Engagement Rate =
(Likes + Comments + Shares + Saves)
÷ Views × 100

Quality Analysis

VYNT can combine available performance signals into a proprietary quality estimate.

Quality analysis may consider:

* Average watch percentage
* Completion percentage
* Engagement
* Profile visits
* Share rate

Dashboard

Analytics can be presented through:

* Metric cards
* Performance charts
* Content tables
* Trend graphs
* Comparison views
* Historical reports

Important Notice

VYNT analytics are derived from available data and are intended to support creator decision-making.

Metrics may differ between platforms because platforms expose different data.

VYNT does not claim that its internal analytics reproduce or represent any third-party recommendation algorithm.
