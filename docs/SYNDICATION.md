VYNT Syndication

Overview

VYNT Syndication provides a structured workflow for distributing authorized content and content metadata to supported destinations.

Destinations

The architecture can support:

* Forums
* Websites
* Webhooks
* Custom APIs

RSS

VYNT can generate RSS 2.0 feeds using configurable filters.

Filters may include:

* Game
* Creator
* Content type
* Topic
* Keyword
* Date range

Moderation Workflow

Syndicated content can move through the following states:

Draft
 ↓
Queued
 ↓
Approved
 ↓
Publishing
 ↓
Published

Failure states may include:

* Failed
* Cancelled

Review

Creators or administrators can:

* Preview
* Edit
* Approve
* Reject
* Retry

Authorization

VYNT Syndication is designed to use authorized integrations.

The platform should not automatically publish to external services without appropriate authorization and configuration.
